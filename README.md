# 🍙 김밥말아 🍙

손님의 주문대로 김밥을 만들어 서빙하고 수익을 올리는 브라우저 게임입니다. 제한 시간(100초) 안에 최대한 많은 수익을 올려 랭킹에 도전하세요.

- **기술 스택**: HTML / CSS / JavaScript, Supabase
- **배포**: Vercel(https://gimbab-game.vercel.app/)

## 실행 방법

1. `clone` 받기
   ```bash
   git clone https://github.com/gimbab-team/GimbabGame.git
   cd GimbabGame
   ```
2. 필요한 환경 변수를 확인합니다. (이름과 사용 위치는 `.env.example`에 정리되어 있습니다)

   | 이름 | 설명 |
   |---|---|
   | `SUPABASE_URL` | Supabase 프로젝트 URL |
   | `SUPABASE_KEY` | Supabase 공개(publishable) 키 |

   이 프로젝트는 브라우저 전용이라 `.env`를 자동으로 읽지 않습니다.
   두 값은 `js/supabase.js` 1~2번째 줄에 상수로 들어 있습니다.
3. VS Code의 **Live Server**로 `html/index.html`을 실행시킵니다.

## Supabase 준비

`users` 테이블이 필요합니다.

| 컬럼 | 설명 |
|---|---|
| `id` | 기본 키 |
| `device_id` | 기기 고유 ID (브라우저 `localStorage`에 저장) |
| `nickname` | 닉네임 |
| `best_score` | 최고 점수 |
| `updated_at` | 최근 갱신 시각 |

## 테스트 계정 가이드

별도의 로그인 기능은 없습니다. 처음 접속한 브라우저에서 닉네임을 입력하면 그 기기가 하나의 계정이 됩니다.

## 게임 방법

1. **김 깔기**: 김을 도마로 끌어다 놓습니다.
2. **밥 푸기**: 밥솥을 누른 채 김 위로 끌어 놓습니다.
3. **재료 올리기**: 말풍선에 적힌 재료만 올립니다. 빼 달라는 재료는 올리지 않습니다.
4. **말고 자르기**: 도마를 더블클릭해 말고, 자르기 버튼을 누릅니다.
5. **서빙**: 자른 김밥을 손님에게 끌어다 줍니다.

잘못 만든 김밥은 쓰레기통으로 끌어 버립니다. 손님은 30초 안에 응대하지 않으면 화가 나서 떠납니다. 제한 시간이 끝나면 결과와 랭킹 화면이 나옵니다.

제한 시간이 끝나면 **최종 수익**(매출 − 재료비)에 따라 등급과 별이 정해집니다.

| 등급 | 별 | 최종 수익 |
|---|---|---|
| 👑 김밥의 달인 | ⭐⭐⭐ | 30,000원 이상 |
| 🍙 김밥 장인 | ⭐⭐ | 15,000원 이상 |
| 🥢 알바생 | ⭐ | 5,000원 이상 |
| 🐥 일반인 | NO STAR | 5,000원 미만 |

## 폴더 구조

```
assets/   이미지
css/      화면별 스타일
data/     손님, 재료, 메뉴 데이터
fonts/    글꼴
html/     화면(시작, 설명, 게임, 결과)
js/       supabase, 닉네임, 결과 화면
js/game/  게임 화면 기능별 모듈(도마, 손님, 서빙, 쓰레기통, 타이머 등)
```
